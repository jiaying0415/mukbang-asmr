## 📖 專案企劃全景與學理架構 (步驟 1 至步驟 6)

### 步驟 1：發掘痛點與創業動機
1. **市售零食咀嚼音頻平淡無奇、收音悶鈍油膩**：普通油炸膨化零食含油量高、容易吸潮軟化，吃播創作者麥克風收音時常有含糊咀嚼音與黏牙雜音，缺乏引發大腦愉悅反應（Tingle）的高頻爆破脆音（Crispy Snap）。
2. **夜間高壓孤獨族群渴望「低負擔聲學療癒」**：都會上班族與學生在深夜面對孤獨與壓力，喜愛觀看吃播 ASMR 獲取放鬆陪伴，但傳統高熱量零食易產生罪惡感，市場缺乏專為「聽覺爆發力」與「健康微卡」兼具的客製零食。
3. **視聽體驗難以跨屏落地為「共時感官共享」**：傳統吃播觀眾永遠只能隔著螢幕流口水，缺乏「我與主播吃同一款聲音」的同步互動儀式感；透過常溫小包裝超取，實現低門檻同頻共嚼。

---

### 步驟 2：外部總體環境 PESTC 深度分析
- **P (政治法律)**：衛福部食藥署對食品標示、無添加防腐劑標準嚴格規範。本企劃堅持 100% 天然食材與常溫低溫微膨化脫水，公開檢驗報告，將嚴格法規化為顧客信任優勢。
- **E (經濟環境)**：抗跌「療癒經濟（口紅效應）」盛行。單價 130~150 元的高 CP 值解壓點心極易促成下單，搭配 60 元常溫超商取貨，大幅降低首購與回購門檻。
- **S (社會文化)**：一人經濟盛行、夜間失眠人口增加，吃播（Mukbang）由單純暴食轉型為「舒壓放鬆、助眠解壓、聲學美學」，ASMR 成為年輕族群日常心靈慰藉。
- **T (科技創新)**：真空急凍昇華技術（Freeze-Drying）與 3D 雙耳立體聲收音器材普及化，造就蜂巢狀超酥脆多孔微氣室結構，能產生突破 72dB 的極致清脆咀嚼音。
- **C (綠色環保)**：選用台灣在地產銷履歷秀珍菇、有機羽衣甘藍，縮短食物里程碳足跡；包裝採用 100% 可回收食品級鋁箔密封袋，落實永續環保。

### 步驟 3：內部資源盤點與假想敵防護
1. **創辦人內部資源評估**：
   - **優勢 (S)**：精準掌握 ASMR 吃播社群語言與聲學美學、善用 AI 輔助與 GitHub Pages 零主機成本架站、無實體店面租金包袱。
   - **劣勢 (W)**：啟動資金微型（3~5 萬元）、初期產能受限於小批量烘烤與凍乾委外打樣、缺乏大宗採購議價優勢。
2. **假想敵精準辨認**：
   - 大型量販賣場之進口大包裝洋芋片與傳統油炸膨化零食（價格低廉、油脂高、收音悶鈍黏牙、化學香精）。
3. **我方定位防護之道**：
   - 絕不進行價格肉搏戰！將戰場移轉至**「70dB 聲學分貝標籤」**、**「無油低卡」**與**「吃播同頻共嚼儀式」**，以聲學科學指標構築競爭對手難以模仿的品質護城河。

### 步驟 4：SWOT 因果推論四象限四部曲綜合矩陣
- **SO 積極開拓策略**：運用 72dB 真空凍乾爆破音與常溫超取優勢，結合社群「#15秒咀嚼爆音挑戰」短影音傳播，迅速吸納年輕失眠族與吃播狂粉。
- **WO 借力補強策略**：因初期產能有限，採取「每週定期限量批次出爐」的線上預購登記制，將產能限制轉化為「新鮮現烘、限量稀缺」的品牌價值。
- **ST 防禦轉化策略**：面對市售一般手工零食的模仿競爭，公開產品音頻頻譜圖、分貝數據與 SGS 無油檢驗報告，以專業聲學規格形成堅實品質壁壘。
- **WT 避險聚焦策略**：嚴格控管原料採購品項，專注於「凍乾蕈菇、琥珀糖、羽衣甘藍」三款核心明星單品，避免庫存積壓，確保資金高周轉與健康現金流。

## 🚀 GitHub Pages 部署四步教學（依手冊 1.1 ~ 1.2）

### 第一步：建立 GitHub 儲存庫 (New Repository)
1. 前往 [GitHub 登入頁面](https://github.com/login)（可用 Google 帳號直接登入）。
2. 點擊右上角「**+**」按鈕，選擇「**New repository**」。
3. Repository name 輸入：`mukbang-asmr`（或任何英文名稱）。
4. 務必勾選「**Public**」（公開），並勾選「**Add a README file**」。
5. 點擊綠色按鈕「**Create repository**」。

### 第二步：上傳 `index.html` 檔案
1. 進入剛建好的儲存庫頁面，點選右上方的「**Add file**」➔「**Upload files**」。
2. 將本專案資料夾內的 `index.html` 直接拖曳至瀏覽器視窗中。
3. 滾動至頁面底部，點擊綠色「**Commit changes**」按鈕。

### 第三步：啟用 GitHub Pages 服務
1. 點擊儲存庫上方橫向功能導覽列的「**Settings**」（設定）。
2. 在左側選單的「Code and automation」中點選「**Pages**」。
3. 在「Build and deployment」底下的「Branch」設定：
   - 將分支由 `None` 改選為 `main`。
   - 資料夾維持 `/(root)`。
   - 點擊右側「**Save**」。

### 第四步：取得公開成果網址
1. 等待約 1~2 分鐘後重新整理頁面。
2. 頂部將出現綠色標籤提示：
   `Your site is live at https://[您的 GitHub 帳號].github.io/mukbang-asmr/`
3. 此網址即為期中報告必須提交之「線上公開部署網址」！
