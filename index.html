Brand Heritage & Vision

品牌故事：從深夜耳機裡的撫慰，到聲學零食的微型落地

「戴上耳機，隔著螢幕聽著吃播主咬下那一聲清脆的喀滋，是無數靈魂在深夜唯一的避風港。」

為什麼我們需要一包「有聲音的零食」？

創辦人是一位重度 ASMR 吃播閱聽人與夜間高壓工作者。無數個加班深夜，正是耳機裡那細膩、俐落、充滿腦內愉悅感（Tingle）的咀嚼音，撫平了焦慮。

然而，現實中市售零食往往令人失望：洋芋片油膩糊口、餅乾死硬黏牙、麥克風收音沉悶且充滿咀嚼雜音，隨之而來的是滿滿的熱量罪惡感。傳統吃播觀眾永遠「只能看、只能聽，卻吃不到同款聲音」。

《喀滋嚼想》因此誕生——我們決定運用微型創業的力量，引進「低溫真空微膨化技術」與「聲學分貝標籤標準」，剔除人工添加與油脂，將大自然的蕈菇、天然寒天與有機蔬果轉化為每克具備 70dB 穿透力的常溫酥脆點心。讓每位觀眾在開播時，也能咬下與主播同頻共振的極致酥脆！

步驟 1

發掘痛點與創業動機（三大核心痛點提煉）

1. 市售零食咀嚼音頻平淡、收音悶鈍油膩

傳統油炸零食含油量高、容易吸潮軟化，吃播主收音時常夾帶含糊咀嚼音與黏牙雜音，缺乏觸發大腦愉悅反應（Tingle）的高頻俐落爆破音。

2. 夜間高壓孤獨族群渴望「低負擔聲學療癒」

都會上班族與學生在深夜觀看吃播 ASMR 尋求慰藉，但常規零食熱量動輒 500 大卡且多添加物，缺乏專為「聽覺爆發力」與「健康微卡」兼具的客製選項。

3. 跨螢幕感官隔閡，缺乏「同頻共時咀嚼體驗」

吃播觀眾長期處於單向觀看狀態，傳統進口吃播食品取得不易或運費高昂；常溫小包裝能大幅降低首購門檻，讓觀眾與創作者達成「同頻共嚼」的互動儀式。

步驟 2

外部總體環境 PESTC 深度分析

P
政治法律 (Political)

衛福部食藥署嚴格規範食品標示與防腐添加物。本企劃堅持 100% 天然食材與無油低溫脫水，公開檢驗報告，將嚴格法規化為信任優勢。

E
經濟環境 (Economic)

抗通膨的「療癒小確幸（口紅效應）」盛行。單價 130~150 元的精緻解壓零食極易引發衝動購買，搭配 60 元常溫超商取貨，首購阻力極低。

S
社會文化 (Sociocultural)

一人經濟崛起與夜間失眠人口劇增，吃播已轉化為身心療癒與心理陪伴的文化載體，ASMR 成為年輕族群日常舒壓的固定儀式。

T
科技創新 (Technological)

真空急凍昇華技術（Freeze-Drying）與高感度雙耳 3D 麥克風普及，使食品結構微孔化達到 70dB 聲學等級，個人創業者亦能精準調校音色。

C
綠色環保 (Conservation)

選用在地小農有機蕈菇與在地羽衣甘藍，縮短食物里程碳足跡；包裝採用可回收食品級鋁箔密封袋，落實環境永續友好概念。

步驟 3

內部資源盤點與假想敵精準防護

💪 創辦人優勢 (S)

• 熟稔聲音聲學美學與吃播社群語言
• 敏捷精實，熟練掌握 AI 輔助與 GitHub Pages 零成本架站
• 無實體店面龐大租金負擔

⚠️ 創辦人劣勢 (W)

• 啟動資金微型（3~5 萬元）
• 初期產能受限於小批量烘烤與凍乾委外打樣
• 缺乏大宗原料採購之議價優勢

🎯 假想敵與定位防護壁壘

主要假想敵：大型量販賣場之進口大包裝洋芋片與油炸膨化零食（價格低廉、油脂高、收音悶鈍、化學香精）。

我方防護之道：絕不進行價格肉搏戰！將戰場移轉至「70dB 聲學分貝標籤」、「無油低卡」與「吃播同頻儀式」，建立獨特的聲學藍海護城河。

步驟 4

SWOT 因果推論四象限四部曲綜合矩陣

🚀 SO 積極開拓策略（發揮優勢 × 掌握機會）

憑藉 72dB 真空凍乾高頻爆破音與常溫超取優勢，發起「#15秒咀嚼爆音挑戰」短影音傳播，快速吸納年輕失眠族與吃播狂粉客群。

💡 WO 借力補強策略（克服劣勢 × 善用機會）

針對小規模產能限制，採行「每週定期限量批次出爐」的線上預購登記制，將產能限制成功包裝為「現烘保鮮、珍貴稀缺」的品牌價值。

🛡️ ST 防禦轉化策略（運用優勢 × 抵禦威脅）

面對同質性手工餅乾模仿，公開產品音頻頻譜圖、分貝數據與 SGS 無油檢驗報告，以專業聲學科學指標構築競爭對手跨不過的品質門檻。

🎯 WT 避險聚焦策略（降低劣勢 × 規避威脅）

嚴格控管初期採購品項，專注於「凍乾蕈菇、琥珀糖、羽衣甘藍」三款核心明星單品，避免庫存積壓，確保資金高周轉與健康現金流。

GitHub Pages Deployment Guide

期中成果 GitHub Pages 部署四步全攻略

依據授課手冊操作指引，將此 index.html 託管於 GitHub Pages 取得全班公開互評網址！

1
建立公開儲存庫 (Repo)

登入 GitHub，點選右上角「+」➔「New repository」，命名為 mukbang-asmr，務必勾選「Public」與「Add a README file」。

2
上傳 index.html 檔案

進入剛開好的儲存庫頁面，點選「Add file」➔「Upload files」，將本單一 HTML 檔案拖曳進去，按下綠色「Commit changes」按鈕。

3
啟用 GitHub Pages 服務

進入儲存庫上方「Settings」➔ 左側「Pages」，在 Branch 設定中將 None 改選為 main，資料夾維持 /(root)，按「Save」。

4
取得公開發表網址

靜待約 1 分鐘後重新整理頁面，頂部出現綠色提示：https://[你的帳號].github.io/mukbang-asmr/，此即為期中作業繳交網址！
